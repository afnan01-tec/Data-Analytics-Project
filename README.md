# Data Analytics Portfolio

A collection of data analysis, machine learning, and dashboard projects. Each project folder contains its own README with the question, data, methods, results, limitations, and visualizations.

## Projects

| Project | Focus | Tools |
|---|---|---|
| [Airbnb Singapore](Data%20Analysis%20with%20Python/readme.md) | Explore listing prices, location, room type, and estimated revenue | Python, pandas, NumPy, Matplotlib, seaborn |
| [Airline Passenger Satisfaction](Data%20Analysis%20with%20a%20Predictive%20Model%20(Machine%20Learning)/readme.md) | Analyze passenger feedback and predict satisfaction with logistic regression | Python, pandas, scikit-learn |
| [EV Charging Network](Excel%20Data%20Preprocessing%20and%20Analysis/readme.md) | Analyze charging sessions, costs, and network usage in an interactive dashboard | Microsoft Excel |
| [Global Education Analytics](Power%20BI%20Dashboard/readme.md) | Compare education indicators, investment, and equity across countries over time | Power BI, Power Query, DAX |

## Repository Layout

```text
Data Analytics Project/
├── Data Analysis with Python/
├── Data Analysis with a Predictive Model (Machine Learning)/
├── Excel Data Preprocessing and Analysis/
└── Power BI Dashboard/
```

Open a project README for its dataset details, analysis, visuals, findings, and limitations. Notebook-based projects include the notebook and data files in their project folders.
